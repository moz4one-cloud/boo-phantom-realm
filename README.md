# $BOO Phantom Realm

An original browser battle game featuring the $BOO ghost mascot.

## Features
- Original Boo character with no legs, feet, or tail
- Turn-based battles
- Attack, shield, healing, and health system
- Unique hats, bags, suits, and colors
- Mobile-friendly game interface

## Project Status
Initial setup.

## Assets
